1. Executive Summary & Architecture Overview

The Asia Group web platform is built as an enterprise-grade, statically optimized Next.js 16 application backed by a decoupled Git-based Content Management System (CMS). All content is maintained in version-controlled Markdown files with frontmatter metadata, allowing non-technical editors to publish via an online CMS UI while keeping all business data securely revisioned in Git.

  • Next.js 16 (App Router): High-speed edge rendering, serverless inquiry endpoints, and automated image optimization.
  • Sveltia Git-CMS: Lightweight browser-based admin panel accessible at /admin without ongoing database hosting overhead.
  • Vercel Enterprise Edge: Global edge CDN hosting with continuous deployment hooks triggered automatically on Git push.
  • Google Analytics 4: Privacy-compliant event telemetry gated behind visitor cookie consent.

3. Content Management Workflows

Method A: Browser-Based CMS Portal (/admin)

Non-technical team members can publish news stories, edit leadership profiles, or update business unit details directly from any web browser:

  1. Access: Navigate to https://www.asiagroup.ng/admin.
  2. Authentication: Click "Login with GitHub". The system validates permissions against the Asia Group GitHub organization.
  3. Editing: Select "Newsroom", "Business Units", or "Leadership" from the sidebar.
  4. Publishing: Fill in article titles, upload high-resolution photography, and click "Publish". Every publish action creates a Git commit on main and triggers a live Vercel rebuild automatically.

Method B: Direct Git / Developer Publishing

Developers can publish directly by placing images in website/public/media/blog-posts/<folder>/ and adding a Markdown file to website/content/news/YYYY-MM-<slug>.md with YAML frontmatter. Pushing to origin main triggers the live deployment.

4. Analytics & Tracking Architecture

The website uses Google Analytics 4 (Property ID: G-9PJBSXMY5L):

  • Consent Gating: Tracking scripts remain completely dormant until a visitor explicitly accepts cookies on the Cookie Consent banner.
  • Execution: Once accepted, localStorage saves asia_group_cookie_consent = 'accepted' and dynamically triggers gtag.js.
  • Live Dashboard: Analytics reports, visitor demographics, and traffic channels live in Google Analytics at https://analytics.google.com under asiagroup.ng@gmail.com.

5. Cloudflare Security Architecture & Implementation

Currently, asiagroup.ng points directly to Vercel's nameservers. Setting up Cloudflare provides enterprise-grade DDoS protection, Web Application Firewall (WAF), and bot mitigation:

  • Option 1 (Recommended & Free) Full DNS Delegation with Cloudflare Proxy: Change nameservers at the .ng registrar to Cloudflare. Point CNAME records to cname.vercel-dns.com with Orange Cloud (Proxied) enabled, and set SSL/TLS mode to Full (Strict). Unlocks Layer 7 DDoS mitigation, WAF rules, Bot Fight Mode, rate limiting on contact forms, and edge caching.
  • Option 2 (DNS-Only / Gray Cloud): Cloudflare handles DNS but proxying is OFF. Zero WAF/DDoS protection (Not recommended).
  • Option 3 (CNAME Partial Setup): Requires a paid Cloudflare Business/Enterprise plan ($200+/month) without any security advantage over Option 1.
